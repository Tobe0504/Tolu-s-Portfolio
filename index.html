    02 / How I work

    1. 01

      Listen

      Customer feedback first, and the business requirement beside it. I came to design through the support desk, so I read complaints as evidence rather than noise.

    2. 02

      Map

      User flows and journey maps, so the whole route is on one wall before anyone argues about a screen. Competitive analysis when it helps to see how others walk it.

    3. 03

      Draw

      Wireframes into high-fidelity interfaces into interactive prototypes, with the words written as carefully as the layout. A journey is only as clear as its copy.

    4. 04

      Hand over

      Usability testing, then patterns back into the design system so the next team inherits the decision. Design handoff is part of the design, not the end of it.
